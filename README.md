# 💰 赚钱计数器（Salary Ticker）

上班时打开这个页面，工资按秒往上跳 —— 正常收入和加班收入分开统计。

**在线使用：** https://tttttttw.github.io/salary-counter/

## 功能

- **两种计薪方式**
  - 年薪制：填年薪 + 每周休息天数（双休/单休/无休）+ 每天工时（默认 8 小时），自动折算日薪和时薪
  - 时薪制：直接填时薪
- **加班（额外收入）**：可开关；倍数可调（默认 1.5 倍）；两种触发方式：
  - 自动：计时满 N 小时后自动进入加班
  - 手动：上班中自己点「开始加班」
- **今日目标进度条**：按日薪/日目标实时推进，多次上下班自动累计
- **带薪摸鱼 🐟**：上班中选摸鱼类型（拉屎 / 尿尿 / 刷抖音 / 发呆 / 看小说 / 茶水间 / 谈恋爱 / 打盹），单独统计摸鱼时长和「偷走的钱」，按类型出明细；摸鱼时段跨过加班门槛的部分按加班费率算
- **麦乐鸡块指数 🍗**：单独一张卡，把本次总收入（或摸鱼偷的钱）换成六国麦乐鸡块数量：中国 / 美国 / 加拿大 / 日本 / 澳洲 / 英国，每块单价是 2026 年 11 月的大概价、写死在代码里（中国按 10 块 ¥21.47 折每块 ¥2.15，中国最划算），数量最多的标 🏆
- **多货币**：工资输入货币 9 种可选（USD / CAD / CNY / JPY / KRW / AUD / EUR / GBP / SGD），九种货币两两组合的汇率（81 个）按 2026-11-03 当天牌价写死在代码里，不调任何 API，切换输入货币时金额自动换算；显示货币 24 种，必含 USD/CAD/CNY/JPY/KRW，外加越南盾、哥伦比亚比索和全球最不值钱的伊朗里亚尔（约 177 万 / 美元）等「数字巨大版」，输出纯属好玩
- **屏幕常亮**：右上角可开 Wake Lock，盯着数字跳

## 锁屏 / 后台说明

网页应用在手机锁屏或切后台时，刷新会被系统冻结。本应用所有金额都按**真实时间戳**计算，并把开始时间、设置和进度存进浏览器本地存储（localStorage）：

- 锁屏、切后台多久都不少算，回到页面自动对齐；
- 误关页面、浏览器被系统回收，重新打开可以接着算；
- 数据只存在本机浏览器，不上传任何服务器。

## 使用

纯静态单文件（`index.html`），无需构建。本地直接用浏览器打开即可，或部署到 GitHub Pages：

仓库 Settings → Pages → Source 选 `main` 分支根目录，保存后得到公开网址，手机浏览器打开后可「添加到主屏幕」当 App 用。
